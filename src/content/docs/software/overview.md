Here you'll find documentation for my various software projects.

## Projects

### [ProtoTracer](/software/prototracer/)

Real-time 3D rendering and animation engine for Protogen LED displays. Powers animated faces on Teensy 4.0/4.1 with support for HUB75 panels and WS2812B LEDs.

### [PTX Engine](/software/ptx-engine/)

Next-generation C++17 evolution of ProtoTracer with cross-platform support, runtime reflection, and Python bindings. Currently under active development.
