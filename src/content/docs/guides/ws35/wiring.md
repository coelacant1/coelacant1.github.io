# Wiring Your Protogen

For complete wiring diagrams and sensor connections, see the [Protocontroller V1.1 guide](/guides/protocontroller-v1/) which includes:

- Sensor wiring diagram for LED panels, microphone, boop sensor, and control button
- Step-by-step wiring pictures
- Power setup instructions

:::tip[Quick Reference]
The wiring diagram shows connections for all four separated LED panels for 100Hz operation along with the MAX9814 microphone, the APDS-9960 boop sensor, and the face control button.
:::
