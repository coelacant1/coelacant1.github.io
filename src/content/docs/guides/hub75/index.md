This guide covers everything you need to know to set up and use your HUB75 Protogen Kit, including wiring, the SmartLED Shield, sensors, and general recommendations.

## Guide Sections

### [Wiring Your Protogen](./wiring/)

Complete wiring diagrams and step-by-step photos for connecting the controller, power source, boop sensor, microphone, and control button.

### [HUB75 LED Panels](./led-panels/)

General information about the HUB75 LED panels, including LED specifications and control options.

### [SmartLED Shield and Breakout](./smartled-shield/)

Detailed documentation for the SmartLED Shield for Teensy 4, including features, Teensy pin usage, controller breakout schematic, PCB designs, and power setup.

### [Sensors and Peripherals](./sensors/)

Information about all supported sensors and peripherals (APDS-9960 boop sensor, MAX9814 microphone, control button, MPU6050, OLED display), plus general recommendations and safety notes.

## Programming

:::tip[ProtoTracer Documentation]
For complete programming instructions and getting started with ProtoTracer, please refer to the [ProtoTracer Documentation](https://coelacant.com/ProtoTracer/).

The ProtoTracer software provides a comprehensive framework for creating animated Protogen faces with the HUB75 kit.
:::
