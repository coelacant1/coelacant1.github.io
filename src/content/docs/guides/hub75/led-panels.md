## General Information

HUB75 LED panels are RGB matrix panels commonly used in LED billboards. They require continuous refresh from a controller and use a parallel interface rather than serial data like addressable LED strips. Each panel is typically 64x32 pixels and can be daisy-chained for larger displays.

For Protogen builds, I recommend using my ProtoTracer program with the SmartLED Shield, which will ray trace a live 3D model of a Protogen face to the LED panel in real time!

An alternative is to use the SmartMatrix library directly with Arduino to display graphics on the panels.
