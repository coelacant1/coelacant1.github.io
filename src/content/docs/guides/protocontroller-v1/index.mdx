The Protocontroller V1.1 is a specialized LED controller board designed for WS2812-based Protogen projects, featuring dual-microcontroller architecture with Teensy 4.0 and ESP32.

## Key Features

- **Teensy 4.0 Core**: High-performance microcontroller for LED animation
- **ESP32 WROVER**: Integrated Bluetooth/WiFi for wireless control and communication
- **WS2812 Support**: Control up to 8 LED strips with 500 pixels each
- **I2C/SPI Breakouts**: Connections for sensors on both Teensy and ESP32
- **USB Programming**: Integrated CP2104 FTDI for ESP32 programming

:::note[Hardware Limitations]
The Protocontroller V1.1 **only supports WS2812 LEDs**. For HUB75 panels or APA102 LEDs, use the [Protocontroller V2](/guides/protocontroller-v2/).
:::
