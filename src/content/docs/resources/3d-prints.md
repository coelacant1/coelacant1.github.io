# Protogen 3D Prints

The [Protogen-3D-Prints](https://github.com/coelacant1/Protogen-3D-Prints) repository contains free, 3D-printable STL files for various Protogen head designs.

## Available Designs

### Sigma Protogen
The latest design, built-in cooling, printable in TPU, lightweight, and easy to print. Recommended for all new builds.

### Epsilon Protogen
The third design release, very hard to print, difficult visor to cut, but all based on visuals.

### Delta Protogen
The second released build, reasonable to print, a bit of a challenge to build.

### Beta Protogen
The first released Protogen build - runs a bit small.

### Gamma Protogen
A compact design optimized for smaller print beds.

### BoxCat WS35 Adapter
An adapter piece for mounting WS35 LED panels in BoxCat-style heads.

## Getting Started

1. **Clone or download** the repository:
   ```bash
   git clone https://github.com/coelacant1/Protogen-3D-Prints.git
   ```

2. **Navigate** to your chosen Protogen variant folder

3. **Import the STL files** into your slicer (Cura, PrusaSlicer, etc.)

4. **Configure print settings** and slice

5. **Print and assemble!**

## Printing Recommendations

### Supports
Most designs require supports - except for the Sigma

### Layer Height
- **Recommended**: 0.2mm or finer for smooth curves
- **Acceptable**: 0.3mm for faster prints with visible layer lines

### Infill
| Use Case | Infill % |
|----------|----------|
| Light wear | 15-20% |
| Regular wear | 20-25% |
| Heavy use | 25%+ |

### Material

| Design | Recommended Material |
|--------|---------------------|
| Beta, Delta, Epsilon | PETG |
| Sigma | TPU (flexible) or PETG |

:::caution[Material Notes]
- **PLA**: Works but may warp in warm environments (cars, conventions)
- **PETG**: Recommended for durability and heat resistance
- **TPU**: Required for Sigma design flexibility
- **ABS**: Suitable but requires enclosure and ventilation
:::
